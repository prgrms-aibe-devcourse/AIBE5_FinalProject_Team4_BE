# 요구사항 정의서

이 문서는 옷장난감의 공식 요구사항 기준 문서입니다. 사용자 요구, 기능 요구, 정책/제약, 세부기능 ID를 하나의 기준으로 정리하며, 구현과 PR 리뷰에서 기능 범위를 판단할 때 이 문서를 우선 확인합니다.

## 문서 위치 기준

- BE 레포: 요구사항 정의서 원본 문서입니다.
- FE 레포: 동일본 또는 요약 동기화본을 둡니다.
- `feature-index.md`는 이 문서의 세부기능 ID를 API, 데이터, 화면과 연결하는 빠른 참조 문서입니다.
- 요구사항 ID 또는 세부기능 ID의 의미가 바뀌면 이 문서를 먼저 수정하거나 같은 PR에서 함께 수정합니다.
- 옷 계절(`CLOTHES.season`)은 옷 등록 시 1개 선택하는 공통 옷 정보이며, 생성된 옷의 계절은 변경하지 않습니다.
- 옷 성별(`CLOTHES.gender`)은 사용자 화면 표시나 직접 수정 대상이 아니라, 옷 분류/추천과 저장 요청에 사용하는 내부 code입니다.

## ID 체계

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 요구사항 ID | 사용자 요구 또는 기능 묶음 단위입니다. | `REQ-RECO-001` |
| 세부기능 ID | 실제 구현, API, 화면, 테스트, 코드리뷰에서 추적하는 세부 기능 단위입니다. | `RECO-001` |
| 도메인(Depth1) | 서비스의 큰 업무 영역입니다. | 제품 추천 |
| 영역(Depth2) | 도메인 안의 하위 업무 영역입니다. | 추천 홈 |
| 요구사항명(Depth3) | 요구사항 묶음의 이름입니다. | OOTD 추천 |
| 세부기능명(Depth4) | 실제 기능 단위의 이름입니다. | OOTD 코디 |

## 사용 기준

- 기능 범위와 우선순위는 이 문서를 기준으로 확인합니다.
- API, DB, 화면 연결은 [feature-index.md](./feature-index.md)에서 빠르게 확인합니다.
- 도메인 용어와 enum/code 값은 [glossary.md](../domain/glossary.md), [catalog.md](../domain/catalog.md), [invariants.md](../domain/invariants.md)를 함께 확인합니다.
- 현재 BE 코드와 요구사항 기준이 다르게 읽히면 [implementation-gaps.md](../backend/implementation-gaps.md)에 기록합니다.
- 날씨, 지역, 체감온도 정보는 독립 추천 기능이 아니라 OOTD, 취향 기반 추천 등 추천 기능의 보조 조건으로 사용합니다.
