# 마케팅 정보 수신 동의

옷장난감 팀 또는 향후 서비스 운영 주체(이하 "운영자")는 이벤트, 서비스 소식, 추천 콘텐츠, 혜택 안내 등 마케팅 정보를 제공하기 위해 아래와 같이 개인정보를 수집·이용하고 광고성 정보를 발송할 수 있습니다.

마케팅 정보 수신 동의는 선택 사항이며, 동의하지 않아도 옷장난감의 기본 서비스 이용에는 제한이 없습니다.

## 제1조 수집 및 이용 목적

| 목적 | 설명 |
| --- | --- |
| 이벤트 안내 | 서비스 이벤트, 챌린지, 프로모션 안내 |
| 서비스 소식 | 신규 기능, 업데이트, 점검, 개선 사항 안내 |
| 추천 콘텐츠 | 개인화 추천, 코디 팁, 스타일링 콘텐츠 안내 |
| 설문 및 의견 요청 | 서비스 품질 개선을 위한 설문, 인터뷰, 피드백 요청 |
| 혜택 안내 | 제휴, 쿠폰, 멤버십, 리워드 등 향후 제공 가능한 혜택 안내 |

## 제2조 수집 및 이용 항목

| 구분 | 항목 |
| --- | --- |
| 회원 식별 | 회원 ID, 닉네임 |
| 연락 수단 | 이메일, 앱 푸시 토큰 또는 서비스 내 알림 수신 정보 |
| 맞춤 안내 | 선호 스타일, 옷장 정보, 추천 피드백, 서비스 이용 이력, 지역 기반 추천 조건 |
| 동의 관리 | 마케팅 동의 여부, 동의 시각 |

회원이 저장한 선호 스타일, 옷장 요약, 추천 피드백 등 서비스 이용 과정에서 생성된 요약 정보는 개인화된 추천 콘텐츠 안내에 활용될 수 있습니다.

## 제3조 광고성 정보 발송 채널

운영자는 이메일, 앱 푸시, 서비스 내 알림, SMS, 카카오 알림톡 등 서비스에서 제공하거나 향후 제공할 수 있는 채널로 광고성 정보를 발송할 수 있습니다.

| 채널 | 사용 기준 |
| --- | --- |
| 이메일 | 가입 또는 로그인 과정에서 확인된 이메일이 있는 경우 |
| 앱 푸시 | 앱 푸시 알림 기능을 제공하는 경우 |
| 서비스 내 알림 | 서비스 내부 알림 기능을 제공하는 경우 |
| SMS | 회원이 휴대전화번호를 제공하고 SMS 수신에 동의한 경우 |
| 카카오 알림톡 또는 유사 메시지 | 해당 채널을 제공하고 회원이 수신에 동의한 경우 |

발송 채널이 추가되거나 수집 항목이 변경되는 경우에는 필요한 범위에서 동의 문구와 수신 거부 방법을 다시 안내합니다.

## 제4조 보유 및 이용 기간

마케팅 목적의 개인정보는 회원이 동의를 철회하거나 회원 탈퇴를 요청할 때까지 이용합니다. 다만 마케팅 동의 상태와 발송 이력은 분쟁 대응, 수신 거부 관리, 계정 복구 가능성을 위해 탈퇴 요청 후 30일 또는 관계 법령상 필요한 기간 동안 보관할 수 있습니다.

| 항목 | 보유 기준 |
| --- | --- |
| 마케팅 동의 여부 | 동의 철회 또는 회원 탈퇴 요청 후 30일 |
| 마케팅 동의 시각 | 동의 상태 확인을 위해 필요한 기간 |
| 발송 이력 | 분쟁 대응과 수신 거부 관리에 필요한 합리적 기간 |

## 제5조 개인정보의 제3자 제공

마케팅 정보 수신 동의는 광고성 정보 발송을 위한 선택 동의이며, 이 동의만으로 회원의 개인정보를 제3자에게 제공하지 않습니다. 제휴사 공동 이벤트, 제휴 혜택 제공 등 제3자 제공이 필요한 경우에는 제공받는 자, 제공 목적, 제공 항목, 보유 및 이용 기간을 별도로 고지하고 회원의 별도 동의를 받습니다.

## 제6조 동의 거부 및 철회

1. 회원은 마케팅 정보 수신 동의를 거부할 수 있습니다.
2. 회원은 마이페이지, 개인정보 수정 화면, 알림 설정 또는 운영자가 제공하는 방법으로 언제든지 동의를 철회할 수 있습니다.
3. 동의를 거부하거나 철회해도 서비스 가입, 로그인, 옷 등록, 추천 등 기본 기능 이용에는 제한이 없습니다.
4. 철회 처리 이후에도 이미 발송이 예약된 메시지는 기술적 사유로 일정 시간 동안 발송될 수 있습니다.
