# 옷장난감 약관 문서 관리

이 폴더는 옷장난감 서비스의 이용약관, 개인정보 처리방침, 마케팅 정보 수신 동의 문서를 관리하기 위한 기준 문서입니다.

## 문서 구성

| 문서 | 목적 | 회원 동의 성격 |
| --- | --- | --- |
| [terms.md](./terms.md) | 서비스 이용 조건, 회원 의무, 서비스 제공 범위, 책임 제한을 안내합니다. | 필수 |
| [privacy-policy.md](./privacy-policy.md) | 개인정보 수집, 이용, 보관, 파기, 제3자 제공/위탁, 회원 권리를 안내합니다. | 필수 |
| [marketing-consent.md](./marketing-consent.md) | 이벤트, 서비스 소식, 추천 콘텐츠 등 광고성 정보 수신 동의를 안내합니다. | 선택 |

## 버전 보관

최신본은 `docs/legal/`의 문서로 관리하고, 실제 적용된 버전은 `versions/` 아래에 날짜별로 보관합니다.

```text
docs/legal/
├── README.md
├── terms.md
├── privacy-policy.md
├── marketing-consent.md
└── versions/
    ├── terms-2026-06-23.md
    ├── privacy-policy-2026-06-23.md
    └── marketing-consent-2026-06-23.md
```

## 버전 관리 기준

| 변경 유형 | 처리 기준 |
| --- | --- |
| 오탈자, 문장 정리, 링크 수정 | `last_updated`만 변경합니다. |
| 수집 항목, 이용 목적, 보관 기간, 제3자 제공/위탁, 회원 권리, 책임 범위 변경 | 새 `version`과 `effective_date`를 부여하고 `versions/`에 보관합니다. |
| 회원에게 불리하거나 중요한 변경 | 적용 전 공지하고 재동의 필요 여부를 검토합니다. |
| 마케팅 수신 범위 변경 | 새 버전 생성 및 선택 동의 문구 재확인 여부를 검토합니다. |

## API 제공 기준

FE 화면은 약관 markdown 사본을 별도로 관리하지 않고 BE API에서 최신 약관 원문을 조회합니다.

| 문서 | API |
| --- | --- |
| 이용약관 | `GET /api/v1/legal/terms` |
| 개인정보 처리방침 | `GET /api/v1/legal/privacy-policy` |
| 마케팅 정보 수신 동의 | `GET /api/v1/legal/marketing-consent` |

API 응답은 `policyType`, `version`, `effectiveDate`, `lastUpdated`, `content`를 반환합니다. `content`는 frontmatter를 제외한 markdown 본문이며, FE는 해당 값을 모달에서 렌더링합니다.

## FE 표시 기준

- 로그인 모달에는 `이용약관`과 `개인정보처리방침` 링크를 제공합니다.
- 옷장난감은 로그인 기반 가입을 기준으로 하며, 신규 가입 또는 온보딩 화면에서는 필수 약관을 확인할 수 있어야 합니다.
- 약관 원문은 BE `GET /api/v1/legal/{documentType}` 응답의 markdown `content`로 표시합니다.
- 온보딩 화면에서는 생년월일, 성별, 선호 스타일, 지역/위치 정보, 프로필 이미지를 입력하거나 확인할 수 있습니다.
- 지역/위치 정보는 날씨 API와 추천 보조 조건에 사용하는 지역 기준 정보입니다. GPS 등 기기 위치정보를 직접 수집하는 기능은 별도 동의 전까지 포함하지 않습니다.
- 마케팅 정보 수신 동의는 별도 체크박스로 제공하며 기본값은 미동의입니다.
- 마케팅 동의는 마이페이지 또는 개인정보 수정 화면에서 동의/철회할 수 있어야 합니다.
- 구매내역 캡처 업로드 화면에서는 주문번호, 결제수단, 카드번호, 배송지, 연락처 등 옷 등록에 필요하지 않은 정보는 가리고 업로드하도록 안내합니다.

## BE 저장 기준

BE는 필수 약관의 사용자별 동의 버전/시각을 별도로 저장하지 않습니다. 이용약관과 개인정보 처리방침은 회원가입 시 자동 동의 기준으로 처리하며, 약관 버전은 `docs/legal/versions/`에서 문서 단위로 관리합니다.

선택 동의인 마케팅 정보 수신 동의는 회원별 현재 동의 상태를 저장합니다.

| 항목 | 설명 |
| --- | --- |
| `marketing_agreed` | 마케팅 정보 수신 동의 여부 |
| `marketing_agreed_at` | 마케팅 정보 수신 동의 시각. 미동의 또는 철회 상태에서는 `NULL`로 관리합니다. |

회원 탈퇴는 `USERS.status`와 `USERS.withdrawn_at`으로 관리합니다. 탈퇴 이력이 없는 활성 계정의 `withdrawn_at`은 `NULL`이며, 탈퇴 요청 시 실제 탈퇴 시각을 기록합니다.

## 서비스 데이터 확인 기준

| 구분 | 약관 반영 기준 |
| --- | --- |
| 로그인/인증 | 카카오, 네이버, 구글 등 로그인 제공자로 계정을 생성하고 식별합니다. |
| 온보딩 정보 | 생년월일, 성별, 선호 스타일, 지역/위치 정보, 프로필 이미지를 맞춤 추천과 프로필 관리를 위해 처리합니다. |
| 지역/위치 정보 | 회원이 입력 또는 선택한 지역 정보를 날씨 API와 추천 보조 조건에 사용합니다. 기기 위치정보는 별도 동의 전까지 수집하지 않습니다. |
| 구매내역 캡처 | 회원이 업로드한 구매내역 이미지에서 상품명, 브랜드, 옵션, 상품 이미지, 구매처 후보 등 옷 등록에 필요한 정보를 추출할 수 있습니다. |
| 마케팅 동의 | 선택 동의이며 가입/온보딩에서 선택하고 마이페이지에서 철회할 수 있습니다. |

## 참고한 기준

- 개인정보 수집·이용 동의: 개인정보 보호법 제15조, 제22조
- 광고성 정보 수신 동의: 정보통신망 이용촉진 및 정보보호 등에 관한 법률 제50조
