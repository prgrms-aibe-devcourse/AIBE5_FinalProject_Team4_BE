# 옷장난감 개인정보 처리방침

옷장난감 팀 또는 향후 서비스 운영 주체(이하 "운영자")는 개인정보 보호법 등 관련 법령을 준수하며, 회원의 개인정보를 안전하게 처리하기 위해 본 개인정보 처리방침을 마련합니다.

## 제1조 개인정보 처리 목적

운영자는 다음 목적을 위해 개인정보를 처리합니다.

| 목적 | 설명                                                    |
| --- |-------------------------------------------------------|
| 회원 가입 및 로그인 | 회원 가입, 회원 식별, 최초 로그인 여부 확인, 인증 토큰 발급                   |
| 온보딩 및 프로필 관리 | 닉네임, 생년월일, 성별, 지역/위치 정보, 선호 스타일, 프로필 이미지 설정 및 수정      |
| 디지털 옷장 제공 | 보유 옷, 미보유 옷, 즐겨찾기, 사이즈, 등록 방식 관리                      |
| 옷 등록 및 AI 분석 | 사진 또는 구매내역 캡처 이미지 업로드, 구매 상품 정보 추출, 의류 정보 추출, 카탈로그 분류 |
| 추천 제공 | 회원 스타일, 옷장 데이터, 계절, 날씨, 피드백을 활용한 상품/코디 추천             |
| 코디북 및 룩피드 제공 | 저장 코디, 피드 게시글, 이미지, 좋아요, 댓글, 저장, 팔로우 관리               |
| 고객 지원 및 오류 대응 | 문의 대응, 장애 분석, 부정 이용 방지, 보안 로그 확인                      |
| 마케팅 정보 발송 | 별도 동의한 회원에게 이벤트, 서비스 소식, 추천 콘텐츠 안내                     |

## 제2조 처리하는 개인정보 항목

운영자는 서비스 제공에 필요한 범위에서 아래 정보를 처리할 수 있습니다.

### 2.1 회원 가입 및 인증

| 구분 | 항목                                |
| --- |-----------------------------------|
| 필수 | 로그인 제공자, 계정 식별자, 이메일               |
| 선택 또는 제공자 정책에 따름 | 닉네임, 계정 프로필 이미지                    |
| 자동 생성 | 회원 ID, 가입일, 최근 로그인 시각, 인증 토큰 관련 정보 |

### 2.2 온보딩 및 프로필

| 구분 | 항목 |
| --- | --- |
| 필수 | 닉네임, 생년월일, 성별, 지역/위치 정보, 선호 스타일 |
| 선택 | 프로필 이미지, 프로필 소개, 외부 링크 |

지역/위치 정보는 회원이 입력하거나 선택한 지역명, 지역코드 등 날씨 조회와 추천 보조 조건에 필요한 지역 기준 정보입니다. GPS, Wi-Fi, 기지국 기반의 기기 위치정보를 직접 수집하는 기능은 별도 동의 전까지 포함하지 않습니다.

### 2.3 옷장, 코디, 추천

| 구분 | 항목 |
| --- | --- |
| 옷장 | 보유/미보유 상태, 옷 이름, 브랜드, 품번, 카테고리, 타입, 계절, 색상, 스타일, 사이즈, 즐겨찾기 |
| 이미지 | 옷 사진, 구매내역 캡처 이미지, 이미지 URL, 피드 이미지 |
| 구매내역 캡처 | 구매내역 원본 이미지, 상품별 썸네일, 상품명, 브랜드, 옵션, 구매처 후보, 주문 상태, 이미지에 포함된 구매 관련 표시 정보 |
| AI 분석 | 분석 결과, 추출된 상품 정보, 추천 설명, 실패 메시지 |
| 추천 | 추천 결과, 추천 피드백, 싫어요, 추천 제외, 저장 여부 |
| 코디/피드 | 코디 구성, 코디북 정보, 피드 게시글, 댓글, 좋아요, 저장, 팔로우 |

구매내역 캡처 이미지에는 주문번호, 결제수단, 카드번호 일부, 배송지, 연락처, 수령인명 등 옷 등록에 직접 필요하지 않은 정보가 포함될 수 있습니다. 서비스는 옷 등록에 필요한 상품 정보 추출을 목적으로 캡처 이미지를 처리하며, 회원에게 불필요한 개인정보를 가리고 업로드하도록 안내하는 것을 권장합니다.

### 2.4 서비스 이용 과정에서 자동 생성되는 정보

| 구분 | 항목 |
| --- | --- |
| 이용 기록 | 접속 일시, 요청 경로, 서비스 이용 기록, 오류 로그 |
| 기기/브라우저 정보 | IP 주소, User-Agent, 브라우저/기기 정보 |
| 보안 정보 | 인증 실패 기록, 비정상 접근 탐지 정보 |

## 제3조 개인정보 수집 방법

운영자는 다음 방법으로 개인정보를 수집합니다.

1. 회원이 로그인을 진행할 때 로그인 제공자로부터 전달받는 정보
2. 회원이 온보딩, 마이페이지, 옷 등록, 코디 저장, 피드 작성 과정에서 직접 입력하는 정보
3. 회원이 업로드하는 옷 사진, 구매내역 캡처, 피드 이미지
4. 서비스 이용 과정에서 자동으로 생성되는 로그와 오류 정보
5. 네이버쇼핑, 날씨 API, AI API 등 외부 연동을 통해 서비스 제공 과정에서 생성되는 결과 정보

## 제4조 개인정보 보유 및 이용 기간

운영자는 개인정보를 수집·이용 목적 달성 시까지 보유합니다. 회원이 탈퇴를 요청하면 계정 상태를 비활성화하고 탈퇴일시를 기록하며, 탈퇴일시로부터 30일 동안은 탈퇴 철회와 계정 복구 가능성을 위해 개인정보와 회원별 데이터를 보관할 수 있습니다. 30일이 경과하면 관련 법령, 분쟁 대응, 부정 이용 방지, 서비스 데이터 품질 유지를 위해 필요한 경우를 제외하고 해당 개인정보를 삭제하거나 익명화합니다.

| 항목 | 보유 기간 |
| --- | --- |
| 회원 계정 정보 | 회원 탈퇴 요청 후 30일 또는 계정 복구 기간 종료 시까지 |
| 로그인 계정 연결 정보 | 회원 탈퇴 요청 후 30일 또는 연결 해제 시까지 |
| 옷장, 코디북, 피드 등 회원별 데이터 | 회원 탈퇴 요청 후 30일 또는 정책상 필요한 기간 |
| 마케팅 동의 정보 | 동의 철회 또는 회원 탈퇴 요청 후 30일 |
| 접속 및 보안 로그 | 보안, 장애 대응에 필요한 합리적 기간 |
| 법령상 보관이 필요한 정보 | 해당 법령에서 정한 기간 |

공통 옷 정보, 상품 정보, 카탈로그 분류 결과처럼 추천 품질 향상을 위해 필요한 서비스 데이터는 회원을 식별할 수 없도록 분리, 익명화 또는 비식별화한 뒤 유지될 수 있습니다.

## 제5조 개인정보의 제3자 제공

운영자는 원칙적으로 회원의 개인정보를 제3자에게 제공하지 않습니다. 다만 다음 경우에는 예외로 합니다.

1. 회원이 사전에 동의한 경우
2. 법령에 따라 제출 의무가 있는 경우
3. 수사기관, 법원 등 적법한 권한을 가진 기관의 요청이 있는 경우
4. 생명, 신체, 재산 보호를 위해 긴급히 필요한 경우

## 제6조 개인정보 처리 위탁 및 외부 연동

서비스 제공을 위해 아래 외부 서비스를 사용할 수 있습니다. 실제 위탁사와 처리 항목은 서비스 운영 전 최종 확정해야 합니다.

| 구분 | 제공 또는 위탁받는 자 | 이용 목적 | 처리되는 정보 |
| --- | --- | --- | --- |
| 로그인/인증 | 카카오, 네이버, 구글 등 로그인 제공자 | 로그인, 계정 식별 | 계정 식별자, 이메일, 프로필 정보 |
| 이미지 저장 | AWS S3 또는 개발 저장소 | 옷 이미지, 구매내역 캡처, 피드 이미지 저장 | 업로드 이미지, 이미지 URL |
| 상품 검색 | 네이버쇼핑 API | 외부 상품 검색, 상품 정보 저장 | 검색어, 상품명, 이미지, 상품 URL |
| 날씨 정보 | 기상청 API 등 | 지역 기반 날씨, 체감온도 조회 | 회원이 입력 또는 선택한 지역 정보 |
| AI 분석 | Gemini API 등 | 의류 이미지 분석, 구매내역 캡처 분석, 추천 설명 생성 | 업로드 이미지, 구매내역 캡처 이미지, 이미지에서 추출된 구매 상품 정보, 상품 텍스트, 옷 정보 |

외부 서비스의 처리 조건은 해당 서비스의 정책에 따를 수 있으며, 운영자는 서비스 제공에 필요한 최소 범위에서 외부 연동을 사용합니다.

## 제7조 위치 정보 처리

현재 옷장난감은 회원이 입력하거나 선택한 지역/위치 정보를 날씨 API 조회와 추천 보조 조건으로 활용하는 기준입니다. 기기의 실시간 위치정보를 직접 수집하거나 위치기반서비스로 제공하는 기능은 별도로 확정하지 않았습니다.

향후 GPS 등 개인위치정보를 수집하거나 위치기반서비스를 제공하는 경우, 별도의 위치기반서비스 이용약관과 동의 절차를 마련합니다.

## 제8조 개인정보 파기 절차 및 방법

1. 운영자는 보유 기간이 경과하거나 처리 목적이 달성된 개인정보를 지체 없이 파기합니다. 다만 회원 탈퇴 요청 시에는 탈퇴일시로부터 30일 동안 탈퇴 철회와 계정 복구 가능성을 위해 개인정보와 회원별 데이터를 보관할 수 있으며, 해당 기간이 경과하면 관련 법령과 보관 예외 사유에 따라 삭제 또는 익명화합니다.
2. 전자적 파일은 복구가 어려운 방식으로 삭제합니다.
3. 종이 문서가 있는 경우 분쇄 또는 소각합니다.
4. 백업 데이터는 운영 정책에 따라 일정 기간 보관 후 안전하게 삭제합니다.

## 제9조 회원의 권리와 행사 방법

회원은 언제든지 다음 권리를 행사할 수 있습니다.

1. 개인정보 열람 요청
2. 오류 정정 요청
3. 삭제 요청
4. 처리 정지 요청
5. 마케팅 정보 수신 동의 철회
6. 회원 탈퇴

권리 행사는 마이페이지, 개인정보 수정 화면, 고객 문의 또는 운영자가 제공하는 절차를 통해 할 수 있습니다. 운영자는 관련 법령에 따라 지체 없이 조치합니다.

## 제10조 만 14세 미만 아동의 개인정보

운영자는 만 14세 미만 아동의 회원가입을 허용하지 않으며, 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 향후 만 14세 미만 아동의 가입을 허용하는 경우에는 법정대리인의 동의 절차와 법정대리인의 권리 행사 방법을 별도로 마련합니다.

## 제11조 개인정보 보호 조치

운영자는 개인정보의 안전성을 확보하기 위해 다음 조치를 적용합니다.

1. 인증 토큰과 민감 정보의 안전한 관리
2. 개인정보 접근 권한 최소화
3. 중요 정보 암호화 또는 보호 조치
4. 외부 API Key와 환경변수 분리 관리
5. 로그와 이미지 접근 경로 보호
6. 보안 취약점 점검과 오류 대응

## 제13조 개인정보 처리방침 변경

1. 본 개인정보 처리방침은 시행일로부터 적용됩니다.
2. 처리 목적, 수집 항목, 보유 기간, 제3자 제공, 위탁 등 중요한 사항이 변경되는 경우 새 버전을 생성하고 변경 내용을 공지합니다.
3. 중요한 변경으로 회원 권리에 영향을 미치는 경우 재동의 필요 여부를 검토합니다.

## 부칙

이 개인정보 처리방침은 2026. 06. 15. 부터 적용합니다.
