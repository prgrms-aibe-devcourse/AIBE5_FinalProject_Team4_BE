<h2 align="center"> 🗂️ Project Overview </h2> 
<p align="center">
  <프로젝트>은/는 사용자의 체형을 토대로 <프로젝트>만의 알고리즘을 적용해<br/>
  <strong>사용자 맞춤형 스타일을 추천해주는 서비스를 제공하는 플랫폼입니다. </strong> <br/>
  <br />
  개발 기간 : 2026.05.19 ~ 2026.06.26 (39일)  
</p>

<h2 align="center"> 🛠️ Features </h2>

<table align="center">
  <thead>
    <tr>
      <th>기능</th>
      <th>설명</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>개인 옷장</td>
      <td>사용자가 온라인으로 옷을 구매한 이력을 캡쳐하여 업로드하면 AI가 분석하여 옷장에 추가</td>
    </tr>
    <tr>
      <td>AI 옷 추천</td>
      <td>
	      사용자의 옷장을 AI가 분석하여 사용자의 취향을 DB에 저장<br>
	   저장된 취향 데이터를 바탕으로 사용자가 마음에 들어할 만한 옷들을 추천
	  </td>
    </tr>
    <tr>
      <td>가상 피팅</td>
      <td>
	      Fashn API를 활용해 마음에 드는 옷을 가상으로 피팅<br>
	  </td>
